## 0.1.0

- Initial release
- 20 pre-built themes: minimal, modern, gradient, card, cupertino, material, dark, neumorphic, dotted, bubble, sunset, ocean, forest, galaxy, retro, neon, pastel, luxury, cyberpunk, coffee
- 16 content builders: text, icon, image, imageWidget, progress, card, expandable, custom, video, code, quote, link, tags, stats, avatar
- Automatic responsive layout (mobile/tablet/desktop)
- Vertical and horizontal timeline axis
- Smooth entry animations (fade + slide per event)
- 14 animated connector styles: growDown, growUp, growOut, wave, pulse, draw, fadeIn, bounce, stagger, wipe, glow, ripple, morph, slideIn
- 4 visual effects: glow, shimmer, sparkle, none
- Animated connectors with solid, dotted, dashed, and gradient line styles
- `number` field on all TimelineEvent constructors for numbered indicators
- Horizontal scroll fix for Windows desktop (mouse wheel + drag)
- 85 unit and widget tests
- Zero external dependencies
